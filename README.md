# AGV-3D-演示

这是一个用于概念可视化的 AGV 3D 交互演示页面（纯静态 HTML + CSS + 少量 JS）。

文件说明：

- `agv.html`：可旋转交互的 AGV 3D 示意页（放在仓库根目录）。
- `README.md`：说明文档（你正在阅读的文件）。

如何打开（本地）：

1. 点击页面右上角的 "Code" 按钮，选择 "Download ZIP"，解压后双击 `agv.html` 用浏览器打开。
2. 或者在文件列表中点击 `agv.html`，在 GitHub 页面中点击右上角的 "Raw" 按钮，然后在新打开的页面中右键另存为 `agv.html`，再本地打开。
3. 支持移动浏览器（把 `agv.html` 传到手机并用手机浏览器打开）。

直接访问（线上）：

- GitHub 仓库：https://github.com/zhao00815/agv-3d-demo
- HTML 文件（查看）：https://github.com/zhao00815/agv-3d-demo/blob/main/agv.html
- HTML 原始内容（Raw）：https://raw.githubusercontent.com/zhao00815/agv-3d-demo/main/agv.html

演示提示：

- 用鼠标按住并拖动画面以旋转视角。
- 当前版本支持旋转；如果需要缩放/平移或更高质量 3D 模型（three.js / glTF），我可以继续升级。
